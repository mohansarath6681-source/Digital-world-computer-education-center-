Digital World PVC Card Print App
================================

इस ZIP में installable mobile web app (PWA) तैयार है।

मुख्य बातें:
- दिया गया Digital World logo app icon और header में लगाया गया है।
- Existing PVC Card PDF password/open, front-back crop और A4 print workflow रखा गया है।
- Clear All में मौजूद JavaScript error ठीक किया गया है।
- Android Chrome में HTTPS वाले hosting (जैसे GitHub Pages) पर खोलकर Install App / Add to Home Screen किया जा सकता है।
- PDF.js अभी CDN से load होता है, इसलिए PDF खोलने के लिए पहली बार Internet ON रखना जरूरी है।

फोल्डर:
- index.html
- manifest.json
- service-worker.js
- icons/icon-192.png
- icons/icon-512.png
